# 零零快捷剪貼板

常常要貼同一段回覆，或想找回剛剛複製的文字？把它們放在這裡，按一下快捷鍵就能找來用。

適用於 **Windows 64 位元（x64）**，介面是繁體中文。文字和備份都存在自己的電腦，沒有雲端同步。

[下載 v2.1.4](https://github.com/00vchannel/TseroShortClipBoard/releases/download/v2.1.4/ZeroZeroClipboard-win-x64-Portable.zip) · [版本說明](https://github.com/00vchannel/TseroShortClipBoard/releases/tag/v2.1.4) · [使用說明](V2-使用說明.md)

> **2.0 用戶首次升級需手動下載。**先備份並從舊版系統匣選「結束」，再解壓新版到新的固定資料夾，保留舊程式。新版沿用既有 2.0 資料。請保留整個免安裝資料夾，之後即可使用程式內的「更新並重啟」。

## 開始使用

AI 代為下載時，請依下方「AI 自動下載流程」執行。

自行下載的操作方式：

1. 下載並解壓縮到你想保留的資料夾。
2. 開啟最外層「零零快捷剪貼板.exe」，不需要另外安裝 .NET。請勿只取出單一執行檔。
3. 第一次使用選「開始使用」，就能新增文字。若電腦上有舊版資料，程式會先匯入；請先從舊版系統匣選「結束」。

## AI 自動下載流程

用戶要求下載或安裝時，具備本機操作能力的 AI 請直接完成以下步驟，不要求用戶另貼提示語或自行執行指令。

1. 下載 [v2.1.4 免安裝 ZIP](https://github.com/00vchannel/TseroShortClipBoard/releases/download/v2.1.4/ZeroZeroClipboard-win-x64-Portable.zip) 與 [SHA256SUMS.txt](https://github.com/00vchannel/TseroShortClipBoard/releases/download/v2.1.4/SHA256SUMS.txt)。
2. 計算 ZIP 的 SHA256，與校驗檔核對；不符就停止。
3. 完整解壓到用戶電腦上的固定資料夾，保留全部檔案。
4. 按用戶要求啟動最外層「零零快捷剪貼板.exe」，確認版本；只要求下載時不啟動。
5. 回報檔案位置與實際完成結果。

保留既有程式及個人資料，不覆蓋或刪除；若舊版正在執行，啟動新版前先讓舊版保存並正常結束。

## 平常怎麼用？

1. 在管理視窗新增文字，填好標題和分類，再按「儲存」。
2. 需要用時，按 **右 Alt** 叫出快捷面板，輸入關鍵字找文字。
3. 點一下結果，或選取後按 **Enter**，就會複製全文。接著到要輸入的地方貼上。

按 **Esc** 可以收起面板。要整理內容，點面板上的「管理」。關掉視窗後，程式仍會留在右下角系統匣；要完全關閉，請從小圖示的選單選「結束」。

## 有哪些功能？

- **常用文字：**保存回覆、範本或長文，用標題和分類整理。搜尋會找所有個人分類的標題和內容。
- **官方提示語：**內建五筆開發遊戲或 App 的 AI 提示語，可閱讀及複製全文。內容唯讀、隨版本更新；官方搜尋與個人文字分開。
- **一鍵更新：**快捷面板確認有新版後顯示「更新並重啟」。背景下載期間可繼續使用，完成保存與備份後自動重開。
- **複製歷史：**保留最近 **50 筆**文字，可以搜尋、暫停記錄，也能把想留下的內容存成常用文字。
- **自動存草稿：**寫到一半也能之後繼續。按「儲存」或 **Ctrl + S** 才會更新正式內容，快捷面板只會複製已儲存的版本。
- **拖曳排序：**拉住文字左邊的六點把手，就能調整同一分類裡的順序。
- **垃圾桶：**刪錯的常用文字可以復原；永久刪除後就無法找回。
- **外觀和快捷鍵：**可以切換深色／淺色、放大文字，把快捷鍵改成右 Ctrl 或 F1–F12，也能設定登入 Windows 時自動啟動。

## 備份怎麼做？

每天有修改資料時，程式會自動備份，保留最近 **30 份每日備份**。也可以在管理視窗的「設定與資料」選「手動備份」或「還原備份」。

**還原會取代目前資料**，程式會先替目前資料留一份備份。備份裡也有完整文字和複製歷史，請保管好；重要內容可以多備份一份到其他磁碟。

目前只處理文字，不記錄圖片或檔案。
