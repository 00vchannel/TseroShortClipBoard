# 零零快捷剪貼板

常常要貼同一段回覆，或想找回剛剛複製的文字？把它們放在這裡，按一下快捷鍵就能找來用。

適用於 **Windows 64 位元（x64）**，介面是繁體中文。文字和備份都存在自己的電腦，沒有雲端同步。

[下載 2.0](https://github.com/00vchannel/TseroShortClipBoard/releases/download/v2.0.0/TseroShortClipBoard_v2.0.0_win-x64.zip) · [使用說明](V2-使用說明.md)

## 開始使用

1. 下載並解壓縮到你想保留的資料夾。
2. 開啟「零零快捷剪貼板 2.0.exe」，不需要另外安裝 .NET。
3. 第一次使用選「開始使用」，就能新增文字。若電腦上有舊版資料，程式會先匯入；請先從舊版系統匣選「結束」。

## 平常怎麼用？

1. 在管理視窗新增文字，填好標題和分類，再按「儲存」。
2. 需要用時，按 **右 Alt** 叫出快捷面板，輸入關鍵字找文字。
3. 點一下結果，或選取後按 **Enter**，就會複製全文。接著到要輸入的地方貼上。

按 **Esc** 可以收起面板。要整理內容，點面板上的「管理」。關掉視窗後，程式仍會留在右下角系統匣；要完全關閉，請從小圖示的選單選「結束」。

## 有哪些功能？

- **常用文字：**保存回覆、範本或長文，用標題和分類整理。搜尋會找所有分類的標題和內容。
- **複製歷史：**保留最近 **50 筆**文字，可以搜尋、暫停記錄，也能把想留下的內容存成常用文字。
- **自動存草稿：**寫到一半也能之後繼續。按「儲存」或 **Ctrl + S** 才會更新正式內容，快捷面板只會複製已儲存的版本。
- **拖曳排序：**拉住文字左邊的六點把手，就能調整同一分類裡的順序。
- **垃圾桶：**刪錯的常用文字可以復原；永久刪除後就無法找回。
- **外觀和快捷鍵：**可以切換深色／淺色、放大文字，把快捷鍵改成右 Ctrl 或 F1–F12，也能設定登入 Windows 時自動啟動。

## 備份怎麼做？

每天有修改資料時，程式會自動備份，保留最近 **30 份每日備份**。也可以在管理視窗的「設定與資料」選「手動備份」或「還原備份」。

**還原會取代目前資料**，程式會先替目前資料留一份備份。備份裡也有完整文字和複製歷史，請保管好；重要內容可以多備份一份到其他磁碟。

目前只處理文字，不記錄圖片或檔案。
