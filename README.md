# 零零快捷剪貼板

常常要貼同一段回覆，或想找回剛剛複製的文字？把它們放在這裡，按一下快捷鍵就能找來用。

適用於 **Windows 64 位元（x64）**，介面是繁體中文。文字和備份都存在自己的電腦，沒有雲端同步。

## 開始使用

使用能操作本機檔案的 AI agent 時，AI 可依下方「AI 自動下載流程」直接完成下載與解壓縮，不需要用戶另貼安裝提示語、執行指令或手動挑選附件。僅瀏覽此網頁不會自動啟動電腦上的 AI。

自行下載的操作方式：

1. 下載並解壓縮到你想保留的資料夾。
2. 開啟最外層「零零快捷剪貼板.exe」，不需要另外安裝 .NET。請勿只取出單一執行檔。
3. 第一次使用選「開始使用」，就能新增文字。若電腦上有舊版資料，程式會先匯入；請先從舊版系統匣選「結束」。

## AI 自動下載流程

本節供正在替用戶下載或安裝本軟體的 AI agent 直接執行。用戶已提出下載或安裝要求時，請自行完成以下工作，不要回覆一段提示語或指令要求用戶自行操作。單純閱讀、介紹或開發本專案不代表安裝授權；仍須遵守執行環境的權限。

1. 確認目的地是用戶的 Windows x64 電腦。只有雲端工作環境或無本機操作能力時，明確說明限制，不得把雲端下載宣稱為已安裝到用戶電腦。
2. 直接下載 [v2.1.4 免安裝 ZIP](https://github.com/00vchannel/TseroShortClipBoard/releases/download/v2.1.4/ZeroZeroClipboard-win-x64-Portable.zip) 與同版 [SHA256SUMS.txt](https://github.com/00vchannel/TseroShortClipBoard/releases/download/v2.1.4/SHA256SUMS.txt)。使用可用的下載工具即可，不需要 GitHub 登入，也不需要複製原始碼或下載 `.nupkg`。遇到逾時先檢查已下載檔案，不重複建立多份。
3. 自行計算 ZIP 的 SHA256，與校驗檔中相同檔名的項目核對。本版 ZIP 的 SHA256 為 `a174123e183a708c0ea01fba14aa16df628858516b6da001c82c8c26f2948f35`。任一核對不符就停止使用該檔案，不解壓或啟動。
4. 優先使用用戶指定的資料夾；否則在本機權限允許時，使用 `%LOCALAPPDATA%\Programs\ZeroZeroClipboard\2.1.4\` 作為固定位置。先檢查目的地；若已有內容，不覆蓋或刪除，核對是否已完成同版下載，或另選新的相鄰資料夾。完整解壓並確認最外層 `零零快捷剪貼板.exe`、`Update.exe` 及 `current/` 都存在，保留整個目錄結構。
5. 若用戶要求啟動或安裝，從最外層 `零零快捷剪貼板.exe` 開啟，核對實際執行路徑及 v2.1.4 版本。若只要求下載，完成下載與核對即可，不額外啟動。若已有舊版運行，可先完成下載，啟動新版前須讓舊版保存草稿並正常結束；不能強制終止。正式升級沿用專案的備份及資料核對規則，不刪除舊程式或使用者資料。
6. 回報已完成的下載位置、核對結果，以及是否確實啟動。若已啟動，簡短說明右 Alt 快捷鍵與「官方提示語」入口。只有遇到必須由本人處理的系統授權或安全提示，才指出具體阻擋；不得停用防護或擅自更改信任設定。

## 平常怎麼用？

1. 在管理視窗新增文字，填好標題和分類，再按「儲存」。
2. 需要用時，按 **右 Alt** 叫出快捷面板，輸入關鍵字找文字。
3. 點一下結果，或選取後按 **Enter**，就會複製全文。接著到要輸入的地方貼上。

按 **Esc** 可以收起面板。要整理內容，點面板上的「管理」。關掉視窗後，程式仍會留在右下角系統匣；要完全關閉，請從小圖示的選單選「結束」。

## 有哪些功能？

- **常用文字：**保存回覆、範本或長文，用標題和分類整理。搜尋會找所有個人分類的標題和內容。
- **官方提示語：**內建五筆開發遊戲或 App 的 AI 提示語，可閱讀及複製全文。內容唯讀、隨版本更新；官方搜尋與個人文字分開。
- **一鍵更新：**快捷面板確認有新版後顯示「更新並重啟」。背景下載期間可繼續使用，完成保存與備份後自動重開。
- **複製歷史：**保留最近 **50 筆**文字，可以搜尋、暫停記錄，也能把想留下的內容存成常用文字。
- **自動存草稿：**寫到一半也能之後繼續。按「儲存」或 **Ctrl + S** 才會更新正式內容，快捷面板只會複製已儲存的版本。
- **拖曳排序：**拉住文字左邊的六點把手，就能調整同一分類裡的順序。
- **垃圾桶：**刪錯的常用文字可以復原；永久刪除後就無法找回。
- **外觀和快捷鍵：**可以切換深色／淺色、放大文字，把快捷鍵改成右 Ctrl 或 F1–F12，也能設定登入 Windows 時自動啟動。

## 備份怎麼做？

每天有修改資料時，程式會自動備份，保留最近 **30 份每日備份**。也可以在管理視窗的「設定與資料」選「手動備份」或「還原備份」。

**還原會取代目前資料**，程式會先替目前資料留一份備份。備份裡也有完整文字和複製歷史，請保管好；重要內容可以多備份一份到其他磁碟。

目前只處理文字，不記錄圖片或檔案。
